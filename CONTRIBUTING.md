# Contributing

Thanks for adding a deal. This list stays useful because every row follows the same rules.

## What belongs here

- **Indie apps for Apple platforms only:** iPhone, iPad, Mac, Apple Watch, Apple TV or Vision Pro, made by an independent developer or a small studio.
- **No** SaaS, web apps, browser extensions, developer tools, courses, books, templates or boilerplates. Other great lists already cover those (see Credits in the README).
- **A real Black Friday / Cyber Monday deal for the current year.** It must be live during the sale window, not a waitlist or a "coming soon".
- **A clear discount:** a percentage, or a before → after price.
- **No 100% off / free giveaways.** A free app with a discounted upgrade is fine.

## How to add a row

1. Add **one entry per app**. If you have several apps, add one row each (or one row for a bundle).
2. Add your row **at the end** of the right category table, under the current year's section.
3. Link straight to the App Store page or your own product page. **No shortened, tracking or affiliate links.**
4. Keep the description to one line: what the app does, not marketing copy.
5. Start the deal with 💸 if it's 50% off or more, and ♾️ if it's a lifetime or one-time purchase.

Row format:

```
| [App Name](https://apps.apple.com/app/id000000000) | iOS, macOS | One line on what it does. | 💸 ♾️ **50% OFF Lifetime** · $39.99 → $19.99 · code `BF26` | Nov 20 – Dec 1 |
```

Columns: App, Platforms (iOS, iPadOS, macOS, watchOS, tvOS, visionOS), Description, Deal (discount first, then before → after price, then code or "no code"), Dates.

## Review

Every pull request is checked by hand. PRs that break the rules, or deals that can't be verified, may be closed. After the sale, expired rows stay in their year's section as an archive.
